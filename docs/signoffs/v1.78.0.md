## Comprehension gate

You will notice nothing. Trips, expenses, splits, payments, undo,
archiving and everything saved on the phone behave exactly as before, and
data on disk is byte-identical in both directions between this build and
the previous one. What changed is internal: the app's working memory now
lives in one small file instead of being scattered through the largest
file in the project, which is what lets the next sixteen decomposition
stories cut that file into pieces a reviewer can read whole.

product**: the owner-gate's first test link was served over an insecure
LAN origin, which silently withholds `crypto.randomUUID`, killing every
id-minting tap (found by the owner; escape E-3, now a checked rule — the
same rig defect retroactively explains sprint 8a's "Create trip" blocker).

zero findings and zero false alarms. The task lane found pre-existing
product friction (filed) and no D-1 defects. E-2 (two nested focus rings)
escaped again on hardware — pre-existing, untouched by this diff.
